<h1 align="center">DiArc</h1>

<p align="center">A beautiful Arc-like floating command bar for Dia and other Chromium browsers.</p>

<h3 align="center">Customizable</h3>
<p align="center">Your shortcuts, sources, quick actions, and layout.</p>

<h3 align="center">Fast</h3>
<p align="center">Find tabs, bookmarks, and history from your keyboard.</p>

<h3 align="center">Minimal</h3>
<p align="center">One floating bar. No new-tab takeover. No tracking.</p>

## Install

1. [Download DiArc](https://github.com/tlolkema/DiArc/archive/refs/heads/main.zip) and unzip it.
2. Open your browser’s extensions page, such as `chrome://extensions`.
3. Enable **Developer mode** → **Load unpacked** → select the folder containing `manifest.json`.
4. Settings opens automatically. Choose your shortcuts and make it yours.

## Use

- **⌥T / Alt+T** — open the overlay, then submit to open a new tab.
- **⌥L / Alt+L** — edit the current URL and navigate in the same tab.
- **↑ ↓** to select · **Enter** to open · **Esc** to dismiss.

Customize sources, quick actions, size, and blur in **Settings**. Changes save automatically.

No build step. No tracking. Browser-protected pages cannot display the overlay. Native shortcuts may remain reserved.
