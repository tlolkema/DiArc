# Customizable
Your shortcuts, sources, quick actions, and layout.

# Fast
Find tabs, bookmarks, and history from your keyboard.

# Minimal
One floating bar. No new-tab takeover. No tracking.

# Use

- **⌥T / Alt+T** — open the overlay, then submit to open a new tab.
- **⌥L / Alt+L** — edit the current URL and navigate in the same tab.
- **↑ ↓** to select · **Enter** to open · **Esc** to dismiss.

Customize sources, quick actions, size, and blur in **Settings**.
