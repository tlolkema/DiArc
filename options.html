Recommended setup

If your browser supports native shortcut remapping, first unassign ⌘T / Ctrl+T and ⌘L / Ctrl+L from its new-tab and address-bar actions. Then assign those keys to DiArc’s New tab and Edit current address commands instead.

Some Chromium browsers reserve these keys. If you cannot release them, use ⌥T / Alt+T and ⌥L / Alt+L.

Open in a new tab⌥ T / Alt T
Edit the current address⌥ L / Alt L
